Lesson 5: time is a service, so a test can own it

Clock is a Reference: every fiber has one without asking (the live clock is its default), and provide(Clock.context(fake)) swaps it for everything inside. sleep(s) never touches asyncio itself. It asks the fiber's Clock to sleep, so a fake Clock makes an hour pass instantly.

1 · sleep(s)

clock_with(lambda c: c.sleep(s)): read the fiber's Clock (a Reference, so R stays Never), then delegate.

2 · live clock decides

s ≤ 0 or NaN: a yield, no timer. inf: never, no timer. Otherwise: async_ with one call_later.

3 · timer fires

resume(succeed(None)); the fiber continues on the loop.

4 · or interrupted

The async_ cancel effect runs handle.cancel(): no stray timer is left on the loop.

Why a leaf module. sleep used to live in the kernel. Routing it through a Clock needs Reference, which lives in context.py, which imports the kernel. So sleep moved to clock.py and the kernel imports nothing from it.
How we know it holds. tests/test_clock_sleep.py spies on the loop's call_later to see each timer registered and cancelled; tests/test_clock.py drives re-anchoring with patched clocks. Making sleep bypass the Clock turns the routing test red. Rows CL1–CL5 in docs/INVARIANTS.md.
