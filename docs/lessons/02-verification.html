The bug Hypothesis found (K7: interrupts land)

Before: wait outside the run loop

  1. P forks C, then P's body finishes: _done(Success)
  2. C still live → interrupt C, register observer, run loop exits
  3. Someone calls P.interrupt_unsafe()
  4. P isn't running or parked → _deferred = True… nobody ever reads it
  5. C publishes → observer publishes P as Success. Interrupt lost.

After: wait is an Async inside the loop (like v4)

  1. P's body finishes: _done stores it in _ending
  2. Interrupt C, evaluate _await_all: P parks
  3. The interrupt arrives: P is parked and interruptible → woken with Failure
  4. _done(interrupt) merges into _ending; C still live → park again
  5. C publishes → P resumes → publishes Failure(Interrupt)
